# p5.js Static JavaScript Template

A template project for using [p5.js](https://p5js.org/) with static [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) and [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript).
